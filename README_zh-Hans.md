# 防具颜色计算器

一个用于自动计算并渲染《Minecraft》中皮革盔甲、皮革马铠以及狼铠染料混合结果的辅助工具。

## 功能

- **混合预览**：选择染料后实时显示防具的颜色变化。
- **版本支持**：支持 JE和BE的最新版本。
- **体型支持**：支持成年和幼年体型（仅针对BE)。
- **智能序列计算**：输入目标颜色，程序自动计算最优染料序列（遗传算法）。
- **批量渲染**：一次性渲染指定长度范围内的所有有效的染料序列，序列的有效性判定遵循zh.minecraft.wiki论坛最新的有关染色防具渲染图命名的提案Diff/1465560与其修正案Diff/1465565。
- **图片导出**：将当前状态导出为 PNG 图片。图片的命名规则遵循zh.minecraft.wiki论坛最新的有关染色防具渲染图命名的提案Diff/1465560与其修正案Diff/1465565。
- **多语言支持**：简体中文、繁体中文、英语、日本语。

## 使用说明

### 手动渲染

1. 选择游戏版本
2. 选择防具类型
3. 选择体型（仅限盔甲）、耐久度（仅限狼铠）
3. 点击染料按钮添加到序列中
4. 实时观察颜色变化
5. 可导出当前状态为图片

### 批量渲染

在“批量渲染”对话框中设置：
- 序列长度
- 目标版本
- 目标防具及其他附加选项

程序会自动生成所有有效的组合并导出为图片。
