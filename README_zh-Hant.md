# 防具顏色計算器

一個用於自動計算並渲染《Minecraft》中皮革盔甲、皮革馬鎧以及狼鎧染料混合結果的輔助工具。

## 功能

- **混合預覽**：選擇染料後即時顯示防具的顏色變化。
- **版本支援**：支援 JE和BE的最新版本。
- **體型支援**：支援成年和幼年體型（僅針對BE)。
- **智慧序列計算**：輸入目標顏色，程式自動計算最優染料序列（遺傳演算法）。
- **批量渲染**：一次性渲染指定長度範圍內的所有有效的染料序列，序列的有效性判定遵循zh.minecraft.wiki論壇最新的有關染色防具渲染圖命名的提案Diff/1465560與其修正案Diff/1465565。
- **圖片匯出**：將目前狀態匯出為 PNG 圖片。圖片的命名規則遵循zh.minecraft.wiki論壇最新的有關染色防具渲染圖命名的提案Diff/1465560與其修正案Diff/1465565。
- **多語言支援**：簡體中文、繁體中文、英語、日本語。

## 使用說明

### 手動渲染

1. 選擇遊戲版本
2. 選擇防具類型
3. 選擇體型（僅限盔甲）、耐久度（僅限狼鎧）
3. 點擊染料按鈕新增到序列中
4. 即時觀察顏色變化
5. 可匯出目前狀態為圖片

### 批量渲染

在「批量渲染」對話框中設定：
- 序列長度
- 目標版本
- 目標防具及其他附加選項

程式會自動生成所有有效的組合並匯出為圖片。
