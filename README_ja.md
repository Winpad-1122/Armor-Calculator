# 防具色計算機

《Minecraft》における革の防具、革の馬鎧、および狼の鎧の染料混合結果を自動計算しレンダリングする補助ツール。

## 機能

- **混合プレビュー**：染料を選択すると防具の色変化をリアルタイムで表示。
- **バージョンサポート**：JEとBEの最新バージョンに対応。
- **体型サポート**：大人と幼体の体型に対応（BEのみ）。
- **インテリジェントシーケンス計算**：目標色を入力すると、最適な染料シーケンスを自動計算（遺伝的アルゴリズム）。
- **バッチレンダリング**：指定した長さ範囲内の有効な染料シーケンスを一括レンダリング。シーケンスの有効性判定は、zh.minecraft.wikiフォーラムの染色防具レンダリング画像命名に関する最新の提案Diff/1465560およびその修正案Diff/1465565に準拠。
- **画像エクスポート**：現在の状態をPNG画像としてエクスポート。画像の命名規則はzh.minecraft.wikiフォーラムの染色防具レンダリング画像命名に関する最新の提案Diff/1465560およびその修正案Diff/1465565に準拠。
- **多言語サポート**：簡体字中国語、繁体字中国語、英語、日本語。

## 使用方法

### 手動レンダリング

1. ゲームバージョンを選択
2. 防具タイプを選択
3. 体型（防具のみ）、耐久度（狼の鎧のみ）を選択
3. 染料ボタンをクリックしてシーケンスに追加
4. 色の変化をリアルタイムで観察
5. 現在の状態を画像としてエクスポート可能

### バッチレンダリング

「バッチレンダリング」ダイアログで設定：
- シーケンス長
- 対象バージョン
- 対象防具およびその他のオプション

プログラムが有効な組み合わせをすべて自動生成し、画像としてエクスポートします。
